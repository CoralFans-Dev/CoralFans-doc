## What is this

CoralFans (CF for short) is a mod for Minecraft BDS with LeviLamina, dedicated to technical survival. CF provides many features that are convenient for technical-survival players (including some that look "illegal" in normal survival), such as item restocking, auto totem, auto tool switching, game speed adjustment, village mechanics visualization, HSA visualization, simulated players, HUD information display, hopper counters, and more. More features are continuously being added.

You can think of CF as the successor of the LL2 Trapdoor plugin. However, CF still lacks some features, such as mob-spawning analysis.

## Plugin features

+ Respects vanilla game mechanics; nothing is modified without informing the player
+ Supports multiplayer
+ Features can be configured via the configuration file
